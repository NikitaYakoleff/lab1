# Лабораторная работа №1 — Продвинутый NumPy

Курс «Python для анализа данных». Пять задач по продвинутому NumPy:

1. **Числа с плавающей точкой** — точность `float32`/`float64`, машинное эпсилон, катастрофическая отмена.
2. **Индексация, срезы и broadcasting** — базовые срезы, fancy-индексация, логическая индексация, broadcasting.
3. **Memory-mapped файлы и оптимизация кэша** — `np.memmap`, сравнение обхода по строкам и по столбцам.
4. **Разреженные матрицы** — форматы CSR / COO / CSC, сравнение с плотными матрицами.
5. **Cython** — сумма квадратов на чистом Python и на Cython, замер ускорения.

## Структура

| Файл | Назначение |
|------|------------|
| `lab1_numpy.py` | Решение всех пяти задач (запускаемый скрипт) |
| `sum_of_squares_cy.pyx` | Cython-реализация суммы квадратов (задача 5) |
| `setup.py` | Сборка Cython-расширения |
| `requirements.txt` | Зависимости |
| `.gitignore` | Исключение артефактов сборки и выполнения |

## Как запустить

```bash
pip install -r requirements.txt
python setup.py build_ext --inplace   # компиляция Cython-модуля (нужен компилятор C)
python lab1_numpy.py
```

> Для компиляции Cython-расширения нужен компилятор C (gcc/clang) и Python
> заголовки (`python3-dev`). Если модуль не скомпилирован, скрипт выполнит
> задачи 1–4, а для задачи 5 выведет подсказку.
